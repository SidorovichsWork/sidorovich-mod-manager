# Changelog

## 0.2.0-beta.1

- English default interface with Spanish and Russian translations.
- Persistent language selector on the home screen, including translated installer errors and background operation messages.
- Separate public beta application ID and release signing identity.
- Permanently integrate tested mods and clear library/backup data that is no longer needed.
- Original synthetic FOMOD test fixtures and translation coverage tests.
- MIT license for original code; bundled dependency license notices.

All 37 automated tests passed, covering package handling, installation/restoration, permanent integration and translation coverage. The creator confirmed that the signed beta works on their Redmi, including the language changes. Compatibility with other devices and individual mods may vary.
